# SmartCPUAIInstaller

A Windows-based script designed to make running local AI models more accessible on low-end hardware and devices with limited system resources.

Uses CPU-based inference and disk streaming techniques to help load and run larger AI models beyond what available RAM alone would typically allow.

The installer automatically detects system hardware, evaluates available resources, and helps configure the environment for local AI inference.

Designed to simplify downloading, installation, and configuration, with a focus on making local AI more accessible without requiring a powerful GPU.

## Key Features

- **Hardware Detection** — Identifies CPU, RAM, GPU, and available storage.
- **CPU-Based Inference** — Supports running models without relying on GPU acceleration.
- **Disk Streaming** — Uses available storage to help accommodate models that exceed available physical memory.
- **Resource Management** — Configures settings based on available system resources.
- **Automated Setup** — Simplifies the installation and configuration process.
